## 小红书 / 中文社区图文稿

标题：第一次写论文，先别让文献和实验记录散成一地

准备大创、第一次进课题组或整理科研经历时，经常卡在同一件事：文章收藏了一堆，笔记在不同软件里，实验跑完只剩一个分数，写正文时不知道哪句话该引哪篇。

这个开源项目叫 PaperTrail。它先帮你建立一套能检查的记录：

- 读过的文献有引用键。
- 准备写进论文的论点有证据卡和章节定位。
- 实验结果有原始附件、输入指纹和复现命令。
- 组会前导出一份可视化报告和进展记录。

仓库自带一个检索小实验，几分钟就能跑通全部流程。故意写错一个引用键，检查器就会指出来。它也附了中文 7 天入门路线和可复制的 AI 辅助提示词。

适合先学会把过程说清楚，再逐步做自己的课题。演示数据是教学小样本，真实科研和申请材料仍要依靠自己完成、理解并能复核的工作。

搜 GitHub：lashonbakker-crypto / papertrail-research。可以先 Star 收藏，再运行 README 的三行命令。
