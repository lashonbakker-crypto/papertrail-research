## 写作前，直接看见记录缺口

- `coverage PROJECT [--json]` 统计文献引用、证据卡人工阅读登记、定位笔记，以及证据卡/指标在草稿中的连接。它只读本地文件，不给论文打分。
- HTML 报告新增“写作前的连接检查”，明确区分待复核与可选连接。未放进正文的背景卡、实验指标可以保留，不必强行使用。
- `check`、`coverage` 和报告统一识别大小写混合的 TODO / 待补；忽略代码、注释以及包含 TODO 字母的其他英文词。
- 保留 v0.2.0 的实验 CSV 导入、原始快照与数值核对；安装版、单文件版与公开下载验证增加覆盖统计及报告检查。

需要 Python 3.10+，运行时零第三方依赖。下载 `papertrail.pyz` 与 `SHA256SUMS.txt`，核对 SHA-256 后：

```bash
python papertrail.pyz --version
python papertrail.pyz demo study
python papertrail.pyz coverage study
```

应显示 `papertrail 0.3.0`。打开 `study/report/index.html`：演示有 2 篇背景文献、2 张证据卡、6 条教学结果，其中 2 条结果连接到草稿，另外 4 条是可选连接。查看 `docs/07-coverage.md` 学习如何理解这些计数。

源码包另有 `python scripts/course_example.py course-study` 完整练习。现有项目、报告、ID 和附件仍拒绝覆盖。计数、人工声明、来源真实性和研究有效性必须区分；工具不重新执行外部实验命令，也不证明论文创新性或录用机会。

### English

Read-only coverage shows registered bibliography, manual reading declarations, evidence locators and manuscript links. The self-contained HTML report now presents the same counts and next steps, distinguishing review tasks from optional links. Draft reminders share one parser across audit and coverage.

Download verification covers checksums, exact tagged source bytes, portable success/error commands, imported CSV integrity and coverage/report behavior. See the actual verification records in `docs/validation.md`. This is a local research bookkeeping workflow, not automatic fact checking or autonomous paper writing.
