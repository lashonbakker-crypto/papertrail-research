## 把自己的实验接入科研记录

- 新增 `import-results`：导入 `method,metric,value,n` CSV，保留原始字节快照、逐指标映射、附件指纹和可选数据/代码指纹。
- `check` 比对 CSV 快照、JSON 和登记表中的数值与来源信息；不重新执行外部命令，明确保留复现提醒。未知附件格式只核对指纹并提醒数值未验证。
- 完整课程例子实际计算训练/测试分开的多数类与阈值分类器结果（toy，accuracy 0.25 / 0.75，n=4），保存逐条预测和实验程序，连接到报告与草稿。该微型数据不支持科研优越性结论。
- 新增 Zotero CSL-JSON 示例及中英步骤。修复空白项目把引用格式说明误判成真实引用的问题；畸形 CSV 返回受控错误。
- 自定义 accuracy / precision / recall 也可在固定 0–1 坐标的 HTML 图表中展示。

### 下载后运行

需要 Python 3.10+。运行时无第三方依赖。

1. 下载 `papertrail.pyz` 和 `SHA256SUMS.txt`，按仓库命令说明核对 SHA-256。
2. `python papertrail.pyz --version` 应显示 `papertrail 0.2.0`。
3. `python papertrail.pyz demo my-first-study` 跑通检索例子。
4. 课程完整示例需要源码包：解压 `papertrail-research-v0.2.0.zip`，进入 `papertrail-research`，运行 `python scripts/course_example.py course-study`。

单文件版支持 `import-results` 和自带检索 demo；源码包另外包含 examples、课程脚本与文档。已有项目、报告、ID 和附件均拒绝覆盖。记录一致性不是研究真实性、有效性或发表保证；并发写入和多文件事务尚未实现。

### English

Import your measured CSV with `import-results`, preserve exact source bytes, and audit the snapshot, registered values, provenance and optional input hashes. Commands are recorded without execution. Unknown artifact schemas explicitly warn that numeric values were not checked.

The source archive includes a computed ten-row classification exercise, per-test predictions, a CSL-JSON example and bilingual instructions. Both model choices use training rows only. The 0.25 / 0.75 toy scores illustrate the workflow, not generalization or superiority. The portable archive supports the importer; the complete course exercise uses the source download.

See `docs/validation.md` and actual Actions runs for verification scope. Invalid input returns 2; checksum consistency is not an identity signature. Files remain local except explicit `add-doi` requests.
