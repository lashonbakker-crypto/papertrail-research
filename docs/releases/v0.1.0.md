# PaperTrail 0.1.0 · 从文献到论文的科研工作流

First working release: local references, evidence cards, measured experiments and an auditable draft.

## Start in a few minutes

Download `papertrail.pyz` and `SHA256SUMS.txt`, verify the checksum, then run:

```bash
python papertrail.pyz demo my-first-study
```

Open `my-first-study/report/index.html`. Python 3.10+ is required; no runtime packages or API key are needed.

## Included

- Unknown citation-key and missing evidence/result checks.
- Artifact SHA-256 and built-in experiment input/value checks.
- Zotero CSL-JSON import and explicit Crossref DOI metadata lookup.
- A computed, self-authored English toy retrieval experiment (8 documents / 12 queries).
- Self-contained HTML, JSON audit, expanded Markdown draft and advisor handoff.
- Chinese first-week guide, portfolio/contribution templates, manual assistant prompts and English documentation.

The source ZIP includes code, original data, tests, guides and templates. `SHA256SUMS.txt` covers both downloads; content hashes are not publisher identity signatures.

The demo is easy and both methods score 1.0; it is not an original research finding or an admissions outcome. The audit checks selected structure and consistency, not scientific validity. Online DOI behavior is covered with fixtures; CLI live Crossref lookup has not been verified in this execution environment.

See README and docs/validation.md for actual verification and limitations. Contributions that make a real research step easier to complete are welcome.
