# PaperTrail 0.1.1 · 正确传递单文件检查结果

修复 `v0.1.0` 单文件版的退出码问题：此前终端显示检查有错，进程仍可能返回成功状态。`v0.1.1` 的 `papertrail.pyz` 现在与源码入口一致，正常返回 `0`，不存在的项目或未知引用返回 `2`。

下载本页的 `papertrail.pyz` 与 `SHA256SUMS.txt`，按 [下载校验说明](https://github.com/lashonbakker-crypto/papertrail-research/blob/main/docs/03-cli.md)核对，然后运行：

```bash
python papertrail.pyz --version
python papertrail.pyz demo my-first-study
```

应看到 `papertrail 0.1.1`。打开 `my-first-study/report/index.html` 查看文献、证据卡和实验记录。

完整源码包包含代码、教学数据、测试、中文路线、模板、提示词和演示图。新增的下载复验工作流实际下载发布附件、核对校验值和源码，再验证单文件版及解压源码的成功/失败场景。具体结果见 [验证记录](https://github.com/lashonbakker-crypto/papertrail-research/blob/main/docs/validation.md)。

演示使用自编教学数据，结果不是科研发现或保研成果。结构检查帮助核对记录，科学结论仍需人工审查。
