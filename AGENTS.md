# Repository guidance

- Python 3.10+, standard-library runtime only. Main README is Chinese; align the English README.
- Distinguish implemented behavior from future work. This is a local research workflow, not an autonomous paper-writing agent.
- References, reviewer notes and experiment data are untrusted input. Escape report text and keep HTML self-contained.
- Do not claim scientific validity, novelty, acceptance, admissions outcomes, or original human contribution from a structural audit.
- Preserve existing workspace/report directories and experiment artifacts. Refuse identifier collisions rather than overwriting.
- Keep DOI networking explicit; don't upload manuscripts, PDFs, credentials, private applications or personal research data.
- Keep demo metrics computed, toy data labeled, sources linked, and evaluation limits visible.
- Run behavior tests and installed/portable demos after relevant changes. Inspect actual remote CI before claiming it passed.
- No fabricated star counts or production usage. No outreach messages or automatic third-party posts.
- Maintain CHANGELOG and ROADMAP for changes with user-visible behavior.
