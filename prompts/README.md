# 可复制的科研辅助提示词

先填入已经核对的材料，再在你选择的 AI 工具中手动使用。这里不调用 API，不把文件自动发送给任何服务。模型回答是辅助意见，最终事实回到原文和实验核对。

## 1. 把大方向拆成一个小问题

```text
我是科研初学者。根据下面的方向、时间、数据与技能限制，提出 3 个能实际检验的小问题。
每个问题写清研究对象、输入、最简单基线、评价指标、需要的数据、可行的两周步骤和关键风险。
缺少的数据请标“待获取”，不要编造文献、结果或声称具有创新性。
我的方向：
已有材料：
时间与技能限制：
```

## 2. 帮我读懂已经拿到的原文

```text
请只根据我粘贴的原文解释内容。先用中文讲作者的问题、方法、假设、结果和范围。
区分作者明确写出的内容与你的推断；解释生词和公式中的每个变量。
给出 2 张候选证据卡：自己的表述、原文定位、适用条件、还需核对的问题。
缺少上下文时说明需要哪一节。不要增加未提供的引用和数字。
文献引用键：
原文与定位：
```

## 3. 检查实验计划

```text
帮我检查这个实验计划。先复述研究问题、允许使用的数据和预测/决策时点。
指出基线是否合适，训练/验证/测试切分是否可能泄漏，指标是否回答问题。
列出最便宜的验证步骤、一个负面/失败场景、需要保留的原始输出。
不运行的实验只能提出计划，不能生成结果。不要把相关性写成因果关系。
计划与数据说明：
```

## 4. 改善表达并逐条对照证据

```text
请根据我的草稿、证据卡和实验表改善表达。保持原意和事实，不扩大结论。
先逐条列出论点→引用键/结果 ID→证据定位；找不到证据的地方标“待补证据”。
然后给修改稿，解释每处关键修改。不要添加新的引用、数字或声称方法最优。
草稿：
证据卡：
实验表与局限：
```

## 5. 准备下一次组会

```text
根据我的真实工作日志写一页组会记录：本周问题、我亲自完成的事、结果证据、失败点、下一步。
区分我的贡献、队友的贡献和 AI 的帮助。没有做的步骤写计划，不写已经完成。
补 3 个导师可能追问的问题，帮我先用简单中文回答。
工作日志与证据：
```
